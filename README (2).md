### What I learned

In this project, I strengthened my understanding of centering layouts using Flexbox, managing spacing, and implementing visual hover effects.

1. **Card Layout & Centering with Flexbox:**
   I used `min-height: 100vh` on the body along with `flex` properties to perfectly center the card on the viewport.

2. **Aligning Elements using Space Between:**
   I used Flexbox to align the price and time-left items seamlessly:

```css
.iconNextdtail {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
